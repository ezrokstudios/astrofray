Privacy Policy (Datenschutzerklärung)

1. Data Controller

The controller responsible for data processing on this website and in the game Astrofray is: Ronald Alexander Korze, M.Sc. (Ezrok Studios), Am Vogeltenn 13 Haus 2, Tür 8, A-4050 Traun, Austria. Contact: ezrokstudios@proton.me.

2. Website Hosting & Server Logs (GitHub Pages)

This website is hosted statically via GitHub Pages (GitHub Inc., USA). When accessing the site, GitHub automatically processes technical server log data (such as IP address, access timestamp, browser type) to ensure system stability and security (Art. 6(1)(f) GDPR). GitHub Inc. is certified under the EU-U.S. Data Privacy Framework (DPF). We do not use tracking cookies, advertising trackers, or user profiling tools. Language preference and toast dismissal state are stored locally in your browser via localStorage.

3. Game Client: Local Saves, Logs & In-Game Newsfeed

The Astrofray game client stores save files, settings, and diagnostic crash logs strictly locally on your device. There is no automated transmission of telemetry, crash dumps, or gameplay data to Ezrok Studios. When fetching the in-game newsfeed, the client requests the static feed.xml hosted on GitHub Pages (ezrokstudios.github.io), which transmits standard connection metadata (IP address) to GitHub Inc. (Art. 6(1)(f) GDPR). For Unity Engine runtime information, please also refer to the Unity Privacy Policy.

4. Contact via Email & External Platforms

If you contact us via email, your provided contact details are used exclusively to process your inquiry and are deleted once the matter is resolved, unless statutory retention periods apply. External links (such as itch.io or Discord) are governed by the respective platform's privacy policies.

5. Your Privacy Rights

Under the GDPR, you have the right to request access (Art. 15), rectification (Art. 16), erasure (Art. 17), restriction of processing (Art. 18), data portability (Art. 20), and objection (Art. 21).

You also have the right to lodge a complaint with the Austrian data protection authority:
Österreichische Datenschutzbehörde (DSB), Barichgasse 40–42, 1030 Vienna, Austria, Web: www.dsb.gv.at.
